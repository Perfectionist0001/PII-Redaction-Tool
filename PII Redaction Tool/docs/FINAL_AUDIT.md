## 5. Problems Found & Fixed

1. **Incorrect Location-Matching and Dedup Hashing**:
   - *Problem*: Entities with identical local offsets in different table cells collided and collapsed.
   - *Fix*: Added hashable `identity_key` property to `PIIEntity` incorporating `table_index`, `row_index`, `cell_index`, etc. Overlap check was restricted to matching source locations.
2. **spaCy NER Over-Span Blocking Name Propagation**:
   - *Problem*: NER tagged `"Sarthak Malvadkar Company"` as one PERSON entity. Propagation created `"Sarthak Malvadkar"`, but overlap resolver dropped it due to length conflict.
   - *Fix*: Refactored Pass 3 to prune over-spans. Prefer propagated known-boundary PERSON/ORGANIZATION names over non-alpha suffixed over-spans.
3. **Sub-Span Containment Conflicts**:
   - *Problem*: Generic terms like `"Hegde"` misclassified as ORGANIZATION (priority 6) blocked the correct full `"Kushal Subbayya Hegde"` PERSON (priority 5) entity.
   - *Fix*: Added sub-span containment checks to `_resolve_overlap` to always prefer the longer entity, preventing partial name leaks.
4. **Merged Cells and Linked Headers Redaction Corruption**:
   - *Problem*: Merged cell and linked header paragraphs were processed multiple times, causing severe text duplication and formatting corruption.
   - *Fix*: Refactored `docx_redactor.py` to group redactions by physical xml paragraph elements (`p_obj._p`) and deduplicate overlaps before applying redactions once.
