## 3. Sensitive Files

The following files contain text extracted from the input corporate prospectus, candidate PII entity strings, or sensitive corporate/personal contact details. While essential for benchmarking and verifying redaction functionality, they require explicit classification:

| Path | Content Description | Sensitivity Classification |
| :--- | :--- | :--- |
| `input/Red Herring Prospectus.docx` | Original financial prospectus file filed with SEBI | **SENSITIVE DOCUMENT**: Contains executive names, physical addresses, personal email addresses, phone numbers, registered corporate addresses, and bank details. |
| `evaluation/ground_truth.json` | 3,428 candidate annotations generated by initial detector pass | **SENSITIVE DATA**: Contains candidate entity strings, character offsets, and surrounding document text snippets. |
| `evaluation/ground_truth_verified.json` | 63 reviewed candidate annotations (15 accepted entities, 48 rejected) | **SENSITIVE DATA**: Contains verified PII strings (e.g. executive names, corporate addresses, personal emails) with exact document coordinates. |
| `evaluation/candidate_annotations.json` | 3,507 raw candidate detections | **SENSITIVE DATA**: Extracted text spans and surrounding context from prospectus. |
| `evaluation/candidate_annotations.md` | Markdown report of candidate detections | **SENSITIVE DATA**: Human-readable context snippets containing PII candidates. |
| `evaluation/review_summary.md` | Summary log of candidate review iterations | **SENSITIVE DATA**: Contains list of candidate texts and classification decisions. |
| `output/redacted_prospectus.docx` | Output document with sensitive PII pseudonymized | **SAFE OUTPUT ARTIFACT**: All genuine PII is replaced with synthetic placeholders (e.g. `"Scott Group"`, `"John Doe"`), making the output privacy-preserving. |
